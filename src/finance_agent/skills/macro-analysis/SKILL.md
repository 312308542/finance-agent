## 适用场景
用于解读利率、信用、汇率、政策和经济周期对 A 股风格与行业的影响。

## 输入
只读取已入库的宏观事件、市场环境、指数表现、资金流和风险上下文。

## 解读口径
先描述宏观变量方向，再映射到行业/风格暴露，最后说明数据滞后和政策不确定性。

## 禁令
不得编造宏观数据、不得引用入库数据之外的事实、不得给目标价、不得修改系统分数、信号方向、风险标记或动作枚举。
