## 适用场景
用于解释回测或实盘复盘中的收益来源、拖累项、风格暴露和交易成本影响。

## 输入
只读取已入库的回测结果、持仓收益、交易记录、复盘任务和风险上下文。

## 解读口径
把收益拆成选股、行业、风格、择时和成本贡献，明确哪些结论可复现、哪些只是样本内现象。

## 禁令
不得自己计算归因、不得引用入库数据之外的事实、不得给目标价、不得修改系统分数、信号方向、风险标记或动作枚举。
