# 私人金融助手 M2 地基实现计划

> **面向 AI 代理的工作者：** 使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框语法来跟踪进度。

**目标：** 先补齐私人金融助手长期运行所需的 M2 数据库、仓储和最小服务层，让后续 `PersonalFinanceAgent` 和金融团队 Workflow 有可落库、可审计、可复盘的地基。

**架构：** 本阶段不接复杂 LLM，也不扩展新的行情数据源。新增普通 PostgreSQL 表承载 Portfolio、Watchlist、DecisionLog、Finance Memory 和 Workflow 审计；服务层只做确定性读写和状态流转，后续 Workflow 调用这些服务。

**技术栈：** SQLAlchemy 2.x、Alembic、PostgreSQL + TimescaleDB、Typer/脚本烟测、中文文档。
