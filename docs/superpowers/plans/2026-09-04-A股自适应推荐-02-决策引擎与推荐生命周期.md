# A 股决策引擎与推荐生命周期实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 让大盘、热门板块、结构、数据质量、收益风险和历史状态共同决定推荐，取消固定买入配额，并把每天的榜单升级为可持续的推荐生命周期。

**架构：** 使用现有 `data_snapshots` 保存冻结的市场、板块、结构和最终决策输入；`DecisionSnapshotBuilder` 负责同一 `as_of` 的完整性门控。现有市场状态、板块强度、结构计算和评分模块继续负责事实计算，新的结构裁决、自适应 Alpha、生命周期和组合构建模块只消费冻结事实，不直接抓取外部数据。

**技术栈：** Python 3.12、SQLAlchemy 2、Alembic、PostgreSQL/TimescaleDB、FastAPI、React 19、TypeScript、Vite、pytest、Node 视图测试、Playwright。
