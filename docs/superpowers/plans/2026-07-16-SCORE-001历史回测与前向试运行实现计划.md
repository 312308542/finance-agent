# SCORE-001 历史回测与前向试运行实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。用户已明确禁止子代理，本计划在当前 `codex/batch1-hermes-o1` 分支内联执行。

**目标：** 新增严格无前视的历史 walk-forward 研究、短线/题材/混合每日不可变截面、5/10/20 日前向观察账本，以及“历史通过即试运行、前向失败自动关闭”的状态机。

**架构：** 历史研究使用独立 `research` 模块和脚本，不修改 GitNexus 标为 HIGH 的 `run_factor_score_topn_backtest`。日常链路复用一次候选池指标/因子/初筛计算，随后对三套策略分别评分；全截面写入现有 `asset_scores`，Top 20 与到期收益写入新增观察表，试运行状态独立持久化。

**技术栈：** Python 3.12、pandas、NumPy、TA-Lib、SQLAlchemy 2、PostgreSQL、Alembic、pytest、GitNexus CLI。
