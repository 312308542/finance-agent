# 基础决策与实时快照链路实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans` 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将方案中最关键的事实版本、可拒绝决策、任务恢复和 gotdx 快照入库能力落到当前 finance-agent，并保持现有推荐、持仓和调度接口兼容。

**架构：** PostgreSQL 追加式 `data_snapshots` 保存跨链路不可变输入，`decision_gates` 保存结构化放行或拒绝结果；`scheduler_task_runs` 提供持久化幂等任务和租约。gotdx 网关仍作为只读 HTTP 数据源，由 Python 适配器把带服务端时间和质量状态的快照写入现有 `realtime_quote_snapshots`，不直接触发交易。

**技术栈：** Python 3.11、SQLAlchemy 2、Alembic、PostgreSQL/TimescaleDB、requests、pytest。
