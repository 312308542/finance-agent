# A 股无前视验证与策略门控实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 建立包含历史股票池、市场/板块/结构、交易成本、T+1 和不可成交约束的无前视 walk-forward，并以历史和前向结果硬性控制策略上线、降级和停用。

**架构：** 深化现有 `strategy_walk_forward.py` 和 `strategy_walk_forward_runner.py`，而不是扩展旧 `replayed` TopN 回测。所有历史事实由点时读取适配器提供，执行仿真由独立模块处理；`StrategyValidationGate` 只消费持久化验证指标并迁移现有 `strategy_trial_states`。

**技术栈：** Python 3.12、pandas、NumPy、SQLAlchemy 2、Alembic、PostgreSQL/TimescaleDB、pytest、Docker Compose。
