# M3 数据可靠性与推荐入池闭环实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 M2 私人金融助手基础上，补齐长期可追踪的数据可靠性地基，并打通“推荐结果 -> 主 Agent 分析 -> 私人观察池”的闭环。

**架构：** 不重做 M0/M1/M2 表，只新增 M3 表保存历史快照、观察池事件和数据质量快照。推荐服务仍负责确定性推荐排序；主 Agent 负责编排推荐结果入池、决策日志、Finance Memory 和复盘任务。

**技术栈：** SQLAlchemy 2.x、Alembic、PostgreSQL + TimescaleDB、Python dataclass、项目现有 Repository / Application Service / PersonalFinanceAgentService。

## 任务 4：主 Agent 推荐入池闭环

**文件：**
- 修改：`src/finance_agent/agents/personal_assistant.py`

- [x] **步骤 1：新增运行摘要 DTO**

新增 `RecommendationIntakeRunSummary`，包含：

- workflow_run_id
- watchlist_item_ids
- decision_ids
- memory_ids
- review_task_ids

- [x] **步骤 2：实现 `sync_recommendations_to_watchlist`**

输入：

- owner_id
- recommendation_run_id
- watchlist_id
- as_of
- limit
- workflow_run_id

行为：

- 读取推荐运行 Top N。
- 跳过 `action=avoid`。
- 写入观察项，来源为 `source_type="recommendation"`。
- 写入观察池事件。
- 写入提醒、决策日志、Finance Memory、复盘任务、Workflow 审计。

实现说明：

- `sync_recommendations_to_watchlist` 从 `asset_recommendations` 读取推荐榜，跳过 `action=avoid`，把非回避推荐写入私人观察池。
- 入池会同时写入 `watchlist_item_events`、`monitoring_alerts`、`decision_logs`、`assistant_memories`、`financial_memory_edges`、`review_tasks` 和 `agent_workflow_events`。
- `manage_watchlist` 的状态流转也已补充观察池事件写入，便于长期追踪观察项生命周期。
