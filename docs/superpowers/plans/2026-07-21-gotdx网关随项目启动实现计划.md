# gotdx 网关随项目启动实现计划

**目标：** 保留现有 Go `gotdx` 行情网关和 Python HTTP 适配器，由 finance-agent 调度器可选地启动、探活、监管并在退出时回收网关进程。

**边界：** 不引入 `pytdx` 到主链路，不修改 `/healthz`、`/quotes`、`/unusual` 契约，不让行情进程故障拖垮推荐、风险和 API 进程。Docker 使用独立 sidecar；Windows 本地调度器使用 Python 监管器。
