# A 股实时行情与点时快照实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 修复 GoTDX 超批量退化，建立持仓秒级、重点池低秒级、全市场分钟级的分层采集，并把实时快照可靠聚合为可回放的 1/5/15/60 分钟 K。

**架构：** `RealtimeQuoteMonitor` 负责选择通道和标的，GoTDX 只采集小批重点对象，AKShare 独立承担低频校验和全市场快照。每个原始快照同时追加写入 `realtime_quote_snapshots` 并覆盖写入 `intraday_quote_latest`；`IntradayBarAggregator` 只从按服务端时间排序的追加事实生成闭合分钟 K。

**技术栈：** Python 3.12、requests、SQLAlchemy 2、Alembic、PostgreSQL/TimescaleDB、Go/GoTDX、Docker Compose、pytest。

```python
GOTDX_GATEWAY_HARD_LIMIT = 100
DEFAULT_GOTDX_BATCH_SIZE = 50


def split_quote_symbols(
    symbols: list[str] | tuple[str, ...],
    *,
    batch_size: int = DEFAULT_GOTDX_BATCH_SIZE,
) -> tuple[tuple[str, ...], ...]:
    """保持输入顺序去重，并按网关安全上限切分行情代码。"""

    if batch_size < 1 or batch_size > GOTDX_GATEWAY_HARD_LIMIT:
        raise ValueError("GoTDX 行情批次必须在 1 到 100 之间")
    normalized = tuple(dict.fromkeys(str(item).strip() for item in symbols if str(item).strip()))
    return tuple(
        normalized[offset : offset + batch_size]
        for offset in range(0, len(normalized), batch_size)
    )
```

将 `GotdxGatewayProvider.fetch_quotes` 改为遍历 `split_quote_symbols`，每个批次分别调用 `/quotes`，最后按原始代码顺序返回合并结果；任一批失败时抛出带批次范围的 `GotdxGatewayError`，不静默丢失股票。

```python
SUPPORTED_INTRADAY_TIMEFRAMES = {"1m": 1, "5m": 5, "15m": 15, "60m": 60}


def aggregate_closed_bars(
    ticks: Sequence[RealtimeQuoteSnapshotORM],
    *,
    timeframe: str,
    close_before: datetime,
) -> tuple[IntradayBar, ...]:
    """按上海交易时段聚合已经闭合的行情桶。"""

    minutes = SUPPORTED_INTRADAY_TIMEFRAMES[timeframe]
    ordered = dedupe_and_sort_ticks(ticks)
    deltas = attach_positive_cumulative_deltas(ordered)
    buckets = bucket_by_session(deltas, minutes=minutes)
    return tuple(
        build_bar(bucket, timeframe=timeframe)
        for bucket in buckets
        if bucket.end <= close_before
    )
```
