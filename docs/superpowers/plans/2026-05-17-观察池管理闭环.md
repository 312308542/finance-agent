# 观察池管理闭环实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在持仓监控闭环之后，补齐私人金融助手的观察池管理能力：持续检查观察池资产，把仍需观察、可升级为候选、应剔除的资产写成结构化决策，并沉淀到 Finance Memory 和复盘任务。

**架构：** 第一版仍使用确定性规则工作流，不调用 LLM。`PersonalFinanceAgentService` 负责读取观察池、聚合信号/风险/记忆/投资假设并写回数据库；`watchlist_management` 工作流只消费结构化上下文并输出状态流转建议。

**技术栈：** Python dataclass、SQLAlchemy 2.x 仓储、M2 应用服务、PostgreSQL + TimescaleDB 冒烟验证。

## 任务 2：观察池工作流协议和规则

**文件：**
- 创建：`src/finance_agent/agents/workflows/watchlist_management.py`
- 修改：`src/finance_agent/agents/workflows/__init__.py`

- [x] **步骤 1：定义输入输出 DTO**

输入包含 owner、watchlist、items、signals、risks、memories、theses、as_of。输出每个观察项的 suggested_action、next_status、summary、risk_rebuttal、next_review_at、removed_reason、证据 ID 和复盘问题。

- [x] **步骤 2：实现确定性规则**

规则：

- high/critical 风险或 bearish 信号：`remove`，状态 `removed`。
- bullish 且 score >= 70 且 confidence >= 0.65，且没有 high/critical 风险：`promote_to_candidate`，状态 `ready`。
- 其他情况：`keep_watch`，状态 `active`。

- [x] **步骤 3：生成中文风险反驳和复盘问题**

每条决策输出中文摘要、反方观点和 2-3 个复盘问题，供决策日志和 Finance Memory 使用。
