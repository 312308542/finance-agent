# A 股交易时段调度收敛实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框语法跟踪进度。

**目标：** 为 A 股盘中任务实现真正的交易时段窗口，使实时行情、资金流和风险情绪在收盘后只补跑两次，盘中触发评估在收盘后停止。

**架构：** 在通用调度任务模型中增加 session_windows，由纯函数统一计算盘中、午休、收盘补跑和下一工作日的执行时间。默认配置、运行时控制 API 和任务监控页读写同一字段；普通 interval、daily_time、新闻公告和最终日 K 保持原行为。

**技术栈：** Python 3.12、pytest、FastAPI/Pydantic、React/TypeScript、Node.js 前端测试、GitNexus。
