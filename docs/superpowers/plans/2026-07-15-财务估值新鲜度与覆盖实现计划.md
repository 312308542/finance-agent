# 财务估值新鲜度与覆盖实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [x]`）语法来跟踪进度。
> **执行状态：** 2026-07-16 已完成，真实验收通过。

**目标：** 将 A 股季度财务报告与日级估值拆分为正确的 freshness 语义，并用现有全市场实时行情报文补齐真实 PE/PB 当前截面。

**架构：** 新增独立的 A 股 freshness 纯函数模块；P0 全市场采集在原事务内幂等写入每日 spot 估值；健康检查分别输出季度财报和日级估值覆盖；因子服务合并 spot 当前估值与 `stock_value_em` 历史序列；基本面增量选择按预期报告期而不是只看采集水位。

**技术栈：** Python 3.12、SQLAlchemy 2、PostgreSQL/TimescaleDB、pytest、AKShare。

```python
ASHARE_SPOT_VALUATION_SOURCE = "akshare:stock_zh_a_spot"
ASHARE_HISTORICAL_VALUATION_SOURCE = "akshare:stock_value_em"

def expected_ashare_report_period(checked_at: datetime) -> date:
    local = checked_at.astimezone(ZoneInfo("Asia/Shanghai"))
    if local.month <= 4:
        return date(local.year - 1, 9, 30)
    if local.month <= 8:
        return date(local.year, 3, 31)
    if local.month <= 10:
        return date(local.year, 6, 30)
    return date(local.year, 9, 30)

def ashare_daily_snapshot_at(collected_at: datetime) -> datetime:
    local_date = collected_at.astimezone(ZoneInfo("Asia/Shanghai")).date()
    return datetime.combine(local_date, time.min, tzinfo=UTC)
```
