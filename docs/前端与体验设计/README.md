# 前端与体验设计

本目录集中保存前端、UI/UX、交互原型、美术方向和资产生产相关文档。

## 内容范围

| 文档 | 用途 |
| --- | --- |
| `界面体验规范.md` | 前端工作台、页面、组件、交互和可访问性规范 |
| `界面体验调研记录.md` | `ui-ux-pro-max` 调研结果和采纳决策 |
| `美术方向.md` | 金融智能体办公室的整体视觉和动效方向 |
| `资产生成提示词.md` | AI 生图、精灵图和 Phaser 可用素材生产提示词 |
| `智能体办公室原创资产与沙盒方案.md` | 前端沙盒办公室、原创资产和交互体验方案 |
| `ui-ux-pro-max-output/` | 设计系统原始输出和页面覆写文档 |

## 维护规则

- 前端体验、页面结构、设计系统、视觉资产和 Phaser 场景相关文档放在这里。
- 推荐链路、数据库、领域协议和数据源设计仍放在 `docs/` 根目录。
- 如果移动或重命名文档，需要同步更新 `docs/项目计划.md`、`docs/架构方案.md` 和 `docs/当前讨论与实施路径.md` 中的引用。
