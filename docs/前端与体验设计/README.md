# 前端与体验设计

本目录集中保存前端、UI/UX、交互原型、美术方向和资产生产相关文档。最新产品定位是私人金融助手，前端体验需要围绕持仓监控、私人观察池、推荐建议、风险反驳、Finance Memory、决策日志和金融团队 Workflow 状态展开。

前端展示记忆时也要区分：Hermes Memory 是通用 Agent 记忆，不直接展示为金融证据；Finance Memory 来自 `decision_logs`、`assistant_memories` 和复盘任务，可以作为历史建议、偏好和复盘摘要展示。

## 内容范围

| 文档 | 用途 |
| --- | --- |
| `界面体验规范.md` | 前端工作台、页面、组件、交互和可访问性规范 |
| `界面体验调研记录.md` | `ui-ux-pro-max` 调研结果和采纳决策 |
| `美术方向.md` | 金融智能体办公室的整体视觉和动效方向 |
| `资产生成提示词.md` | AI 生图、精灵图和 Phaser 可用素材生产提示词 |
| `智能体办公室原创资产与沙盒方案.md` | 前端沙盒办公室、原创资产和交互体验方案 |
| `ui-ux-pro-max-output/` | 设计系统原始输出和页面覆写文档 |

## 维护规则

- 前端体验、页面结构、设计系统、视觉资产和 Phaser 场景相关文档放在这里。
- 推荐链路、数据库、领域协议和数据源设计仍放在 `docs/` 根目录。
- 前端不要展示隐藏推理链，只展示 `agent_workflow_events`、证据摘要、风险反驳和用户可确认动作。
- 办公室沙盒里的角色是后端 Workflow 状态投影，不等于后端自由推理过程本身。
- 如果移动或重命名文档，需要同步更新 `docs/项目计划.md`、`docs/架构方案.md` 和 `docs/当前讨论与实施路径.md` 中的引用。
