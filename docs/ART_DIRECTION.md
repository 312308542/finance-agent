# 金融 Agent 办公室美术方向

更新时间：2026-05-13  
适用范围：`apps/agent-office`、Penpot 原型、AI 生图资产、后续 Phaser 场景

## 1. 美术目标

我们要做的不是传统金融后台，也不是普通像素小游戏，而是一个“金融 Agent 作战办公室”：

- 用户第一眼能感知：这里正在分析股票、数字货币、持仓、风险和订单草案。
- Agent 小人不是装饰，而是系统状态的可视化表达。
- 画面要有经营类游戏的生命感，但不能幼稚、杂乱或过度可爱。
- 金融结论、证据链和风险确认仍然由 React 面板承载，Phaser 世界负责氛围、进度和协作状态。

一句话方向：

```text
专业金融工作台 + 轻量沙盒办公室 + 像素/2.5D 角色动画 + 可审计 AI 协作现场
```

## 2. 视觉关键词

主关键词：

- 金融作战室。
- AI 团队协作。
- 经营类办公室。
- 实时运营。
- 风控警戒。
- 数据管道。
- 证据链。
- 下班/值班状态。

反关键词：

- 营销页。
- 大面积紫色 AI 渐变。
- 生活化小屋。
- 雪山木屋。
- 股票软件复刻。
- 赛博朋克夜店。
- 儿童游戏。
- 满屏调试线框。

## 3. 推荐风格

第一版推荐采用“清晰像素等距风”：

- 画面比例：16:9。
- 基础尺寸：1280x720。
- 角色：48x48 或 64x64。
- 背景：等距或轻等距办公室，区域清楚，通道明确。
- UI：React 面板采用现代金融工作台风格，不强行像素化所有控件。

原因：

- 像素角色更适合用 spritesheet 做动画。
- AI 生图工具更容易稳定生成“办公室大场景”。
- Phaser 渲染成本低。
- 和经营类游戏体验天然接近。

不建议第一版直接做：

- 复杂 3D 办公室。
- 高写实角色。
- 高帧率逐角色复杂动画。
- 全 Tiled 地图生产流程。

## 4. 色彩系统

### 4.1 主色调

背景色：

- 深石墨黑：`#0B1017`
- 深蓝灰：`#111827`
- 面板深灰：`#18202D`

文字：

- 主文字：`#E5E7EB`
- 次级文字：`#94A3B8`
- 弱提示：`#64748B`

金融状态：

- 正向/盈利/通过：`#22C55E`
- 风险/亏损/阻断：`#EF4444`
- 待确认/注意：`#F59E0B`
- 数据/中性信息：`#38BDF8`
- 研究/证据：`#EAB308`

### 4.2 使用原则

- 红色只用于风险、亏损、阻断和强警告。
- 绿色只用于盈利、通过、健康状态。
- 琥珀色用于待确认、注意和未完成。
- 蓝色用于数据流、选中态和中性状态。
- 紫色只保留少量用于“订单草案/审批夹”，不能作为全局主色。

### 4.3 禁止

- 单一蓝色铺满页面。
- 大面积紫蓝渐变。
- 纯装饰光球、光斑、bokeh。
- 高饱和霓虹铺满背景。
- 红绿同时大面积闪烁。

## 5. 办公室区域设计

办公室应拆成稳定功能区，便于 Phaser 做工位、路径和交互热点。

```text
左侧：数据机房 / 数据管道 / 行情接入屏
中左：信号分析台 / 多屏图表 / 指标计算台
中部：圆桌会议区 / Agent 讨论区
右侧：风控室 / 警报屏 / 仓位雷达
右下：审批门 / Hermes 出单闸口 / 订单草案打印区
左下：休息区 / 下班待命区 / 低亮度值班灯
顶部：市场状态屏 / 数据源健康屏 / 世界时钟
```

### 5.1 数据机房

视觉元素：

- 小型服务器柜。
- 数据管道。
- 行情流光。
- API 接入终端。
- 缺失数据提示灯。

语义：

- 数据拉取。
- 数据清洗。
- 数据健康检查。
- Raw Store 到 Canonical Store。

### 5.2 信号分析台

视觉元素：

- 多屏 K 线。
- 指标仪表。
- 小型雷达图。
- 信号卡片打印口。

语义：

- 技术指标。
- 基本面信号。
- 合约信号。
- 事件信号。
- 组合信号。

### 5.3 风控室

视觉元素：

- 红色警戒屏。
- 仓位热力图。
- 爆仓距离仪表。
- 风险阻断门。

语义：

- 杠杆风险。
- 回撤风险。
- 集中度风险。
- 数据不可用阻断。
- 订单草案复核。

### 5.4 圆桌会议区

视觉元素：

- 圆桌。
- 椅子。
- 白板。
- 证据贴纸。
- 分歧标记。

语义：

- 多 Agent 协作。
- 反方观点。
- 推荐汇总。
- 总协调员裁决。

### 5.5 审批门

视觉元素：

- 出单闸口。
- 打印机。
- 待签字文件夹。
- Hermes 接口终端。

语义：

- 订单草案。
- 用户二次确认。
- CLI/MCP 调用。
- 模拟交易或 testnet。

### 5.6 休息区

视觉元素：

- 低亮度休息位。
- 值班小屏。
- 市场闭市灯牌。
- 夜间审计小台灯。

语义：

- 闭市。
- 下班。
- Crypto 值班。
- 夜间批处理。

## 6. Agent 角色设定

每个 Agent 必须有稳定的人格、服装、道具、工作区域和动作。角色要能从小尺寸轮廓中区分出来。

| Agent | 主色 | 性格 | 视觉识别 | 工作区 | 最小动作 |
|---|---|---|---|---|---|
| 数据管家 | 蓝色 | 严谨、安静、校验癖 | 数据终端背包、蓝色工牌 | 数据机房 | idle、walk、working、offDuty |
| 信号分析师 | 绿色 | 快节奏、技术派、接受反驳 | 多屏眼镜、图表徽章 | 信号分析台 | idle、walk、working、thinking |
| 风险官 | 红色 | 冷静、保守、会打断 | 红色警戒徽章、夹板 | 风控室 | idle、walk、working、blocked |
| 研究员 | 金色 | 慢热、证据派 | 笔记本、资料夹、便签 | 圆桌/资料台 | idle、walk、working、thinking |
| 草案员 | 紫色 | 流程控、等待确认 | 审批夹、打印纸 | 审批门 | idle、walk、working、approved |
| 总协调员 | 青蓝 | 温和但决断 | 领队标识、记录板 | 圆桌 | idle、walk、working、approved |

## 7. Agent 动作语义

动作不仅是动画，而是系统状态。

```text
idle        无任务，原地待命
walk        前往目标工位
working     正在处理任务
thinking    正在分析或等待更多证据
arguing     多 Agent 出现分歧
blocked     风控阻断或数据不可用
approved    推荐或草案通过
offDuty     闭市、下班或休眠
```

第一版只强制：

```text
idle
walk
working
offDuty
```

其余动作可以先用状态图标或气泡替代。

## 8. 画面层级

Phaser 层级建议：

```text
background      办公室底图
ambientFx       数据流、屏幕闪烁、值班灯
agents          Agent 角色
foreground      前景遮挡物
taskHints       小型任务提示，不放长文本
interaction     点击热区
```

React 层级建议：

```text
topStatusBar    市场状态、账户状态、数据源健康
rightPanel      推荐、风险、证据摘要
bottomTimeline  Agent 事件流和任务进度
drawer          证据链、持仓详情、订单草案确认
```

Phaser 不承载长文本，不展示复杂表格。复杂信息都进入 React 面板。

## 9. 交互原则

用户可以交互：

- 点击 Agent：查看该 Agent 当前任务、输入、输出、证据摘要。
- 点击工位：查看该区域的模块状态，例如数据源健康、信号质量、风控告警。
- 点击任务卡：查看任务进度、结果和失败原因。
- 点击审批门：查看订单草案，进行确认或拒绝。
- 切换世界时段：查看开盘、闭市、夜间审计、风险事件状态。

用户不需要：

- 直接操控小人走路。
- 理解底层指标公式。
- 在主画面看长篇报告。
- 手动触发每个 Agent。

## 10. 动画原则

必须有动画：

- Agent 呼吸/待命。
- Agent 行走。
- 工作时的小动作。
- 数据流轻微闪烁。
- 风险告警短暂突出。
- 夜间/闭市状态灯光变化。

需要节制：

- 不要所有元素同时闪。
- 不要长时间红色闪烁。
- 不要让动画干扰阅读。
- 支持 `prefers-reduced-motion` 时降低动效。

## 11. 金融语义与视觉映射

| 金融状态 | 视觉表达 |
|---|---|
| 数据刷新 | 数据管道亮起，数据管家走向机房 |
| 数据缺失 | 机房出现琥珀提示灯，数据管家进入 working |
| 信号增强 | 信号分析台发出绿色短光，生成信号卡 |
| 信号冲突 | 圆桌出现分歧标记，研究员和信号分析师讨论 |
| 风险升高 | 风控室红灯短闪，风险官移动到目标区 |
| 风控阻断 | 审批门关闭，草案员等待，风险官举牌 |
| 草案通过 | 审批门出现绿色通过灯 |
| A 股闭市 | 大屏变暗，多数 Agent 去休息区 |
| Crypto 值班 | 保留一名值班 Agent 和小屏流光 |
| 夜间审计 | 数据机房和日志屏低亮运转 |

## 13. 第一版验收标准

第一版原创资产切片达到以下标准即可进入实现：

- 背景一眼能看出是金融/数据/风控办公室。
- 至少 2 个 Agent 可区分：数据管家、风险官。
- Agent 有待命、行走、工作、下班四类状态。
- 办公室至少有数据机房、信号台、风控室、圆桌、审批门、休息区。
- 角色移动路径不会穿过明显障碍物。
- 闭市/下班状态有明显视觉变化。
- 主画面不出现长文本和密集表格。
- 证据链、推荐、持仓、订单草案在 React 面板中展示。
