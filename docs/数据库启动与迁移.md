# 数据库环境搭建

本文档说明本地和其他环境如何启动 PostgreSQL + TimescaleDB、Redis，并执行 M0 数据库迁移。

## 1. 启动基础设施

```bash
docker compose up -d postgres redis
```

PostgreSQL + TimescaleDB 默认连接信息：

```text
host: localhost
port: 5432
database: finance_agent
user: finance_agent
password: finance_agent
```

容器初始化脚本会执行：

```sql
CREATE EXTENSION IF NOT EXISTS timescaledb;
```

Redis 默认连接信息：

```text
host: localhost
port: 6379
database: 0
url: redis://localhost:6379/0
```

Redis 只用于热数据缓存、Agent 输入上下文缓存、任务锁和 Provider 熔断状态。历史 K 线、财务快照、原始响应、推荐结果和证据链仍然必须写入 PostgreSQL + TimescaleDB。

## 2. 安装后端依赖

```bash
python -m pip install -e ".[dev]"
```

## 3. 执行迁移

```bash
alembic upgrade head
```

连接地址可通过环境变量覆盖：

```bash
export FINANCE_AGENT_DATABASE_URL=postgresql+psycopg://finance_agent:finance_agent@localhost:5432/finance_agent
export FINANCE_AGENT_REDIS_URL=redis://localhost:6379/0
```

Windows PowerShell：

```powershell
$env:FINANCE_AGENT_DATABASE_URL = "postgresql+psycopg://finance_agent:finance_agent@localhost:5432/finance_agent"
$env:FINANCE_AGENT_REDIS_URL = "redis://localhost:6379/0"
alembic upgrade head
```

## 4. 验证仓储层

数据库启动并迁移完成后，可以运行仓储层冒烟脚本：

```bash
python scripts/storage/smoke_repositories.py
```

脚本会写入：

- 一个 A 股样例资产。
- 一个数字货币样例资产。
- 一个 A 股候选池。
- 一个数字货币候选池。
- A 股日线和数字货币 1h K 线。

该脚本可以重复运行，用于验证 Repository 的幂等写入和基础查询。
拆分后的候选池成员 ID 会带上候选池 ID，避免和历史混合冒烟数据发生主键冲突。

市场边界可以用轻量脚本单独验证：

```bash
python scripts/data/smoke_market_boundaries.py
```

该脚本不写数据库，用于确认 A 股和数字货币不能进入同一个候选池、同一次初筛或同一次推荐运行。

也可以运行统一基础数据采集命令：

```bash
python scripts/data/collect_base_data.py --group ashare-p1 --limit 5
python scripts/data/collect_base_data.py --group crypto --limit 5
python scripts/data/collect_base_data.py --group ashare-risk --limit 5
python scripts/data/collect_base_data.py --group all --limit 5
```

该命令按分组调用 `AshareP0Collector`、`AshareP1Collector`、`AshareP2Collector`、`AshareRiskSentimentCollector` 和 `CryptoDataCollector`，把 A 股 P0/P1/P2、风险情绪与数字货币基础数据写入标准表，并为每次 Provider 调用归档 `raw_records`。命令会输出 JSON 摘要，包含每个任务的状态、采集条数、`raw_record_id`、缓存连接状态，以及是否因为任务锁或 Provider 熔断被跳过，适合作为后续调度器和任务日志的基础入口。

采集命令已接入 Redis 任务锁和 Provider 熔断状态：

```bash
python scripts/data/collect_base_data.py --group all --limit 5 --cache-backend redis
python scripts/data/collect_base_data.py --group ashare-risk --limit 5 --force-provider
```

关键参数：

- `--cache-backend auto|redis|null`：`auto` 适合本地调试，会在 Redis 不可用时降级为空缓存；正式调度建议使用 `redis`。
- `--lock-ttl-seconds`：同参数采集任务锁 TTL，默认 600 秒。
- `--circuit-failure-threshold`：Provider 连续失败多少次后打开熔断，默认 3 次。
- `--circuit-cooldown-seconds`：Provider 熔断冷却时间，默认 900 秒。
- `--force-provider`：忽略当前熔断状态，强制执行一次采集。

基础数据层健康检查可以只读数据库和 Redis，不请求任何第三方数据源：

```bash
python scripts/data/check_base_data_health.py --cache-backend redis
```

该脚本会输出关键表数据量、候选池成员数量、最近 Provider 调用状态、Redis 中的 Provider 熔断状态，以及当前数据缺口。它适合放在调度器后置检查、手工巡检或进入因子计算前的前置检查中。

基础数据调度器可以按配置编排上述采集入口：

```bash
python scripts/data/run_base_data_scheduler.py --print-plan
python scripts/data/run_base_data_scheduler.py --run-once --dry-run
python scripts/data/run_base_data_scheduler.py --loop --dry-run --max-cycles 1
```

调度器支持全局开关、单任务开关、任务频率、外部 JSON 配置和 dry-run。详细说明见 `docs/基础数据调度器.md`。

也可以运行旧的真实数据源到数据库冒烟脚本：

```bash
python scripts/data/smoke_providers.py
```

该脚本会尝试读取 AKShare A 股日线和 ccxt Binance K 线。公网接口可能因为网络、SSL 或数据源限流失败；失败时 Provider 应返回结构化 `error`，不能让异常穿透到推荐链路。

数字货币基础数据可以单独运行：

```bash
python scripts/data/smoke_binance_native.py
```

该脚本会通过 `CryptoDataCollector` 采集 Binance 现货交易对列表、BTCUSDT 1h K 线，以及 BTCUSDT U 本位合约的资金费率、标记价/指数价、未平仓量和多空账户比；分别写入 `assets`、`asset_universes`、`asset_universe_members`、`market_bars` 和 `crypto_derivative_snapshots`。每次 ccxt/Binance 原生 Provider 调用都会写入 `raw_records`。Binance 公网接口可能因为地区、网络或限流返回错误；这类错误应表现为结构化 `error` 并保留审计记录。

Agent 上下文缓存可以单独运行：

```bash
python scripts/data/smoke_agent_context_cache.py
```

该脚本会验证 Redis JSON 缓存、轻量锁和 `AgentContextBuilder`。它默认读取 `ashare:000001` 的基础数据、事件和证据，构建短 TTL Agent 输入上下文。

A 股 P1 行业、概念、资金流和新闻数据可以单独运行：

```bash
python scripts/data/smoke_akshare_p1.py
```

该脚本会尝试采集行业成分、概念成分、个股资金流和个股新闻。当前环境下行业/概念成分接口仍可能被东方财富上游断开；Provider 会先记录 AKShare/东财 curl 失败链路，再尝试同花顺详情页首屏轻量 fallback，并写入 `asset_universes` 与 `asset_universe_members`。个股资金流主源失败时会尝试同花顺资金流 fallback，并写入 `capital_flow_snapshots`。所有调用成功和失败都会归档到 `raw_records`。

A 股 P2 财务和估值数据可以单独运行：

```bash
python scripts/data/smoke_akshare_p2.py
```

该脚本会读取平安银行的主要财务指标和个股估值序列，并写入 `fundamental_snapshots`；同时会请求业绩报表接口，若当前网络下东方财富 datacenter 超时，也必须把失败响应写入 `raw_records`。脚本用于验证 P2 Provider、归一化、JSONB 安全清洗和原始响应归档链路。

## 5. 设计约束

- 全环境必须使用 PostgreSQL + TimescaleDB。
- 不使用 SQLite 作为应用运行环境或测试环境。
- `market_bars` 是 TimescaleDB hypertable，唯一约束必须包含 `timestamp`。
- `crypto_derivative_snapshots` 是 TimescaleDB hypertable，主键必须包含 `as_of`。
- 指标、因子、信号和评分保存的是推荐链路快照，不是实时指标流水。
- Redis 是可重建缓存和任务协调层，不保存唯一事实。
