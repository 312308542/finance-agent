# 方案 11：工程债务清理与可复现性收尾

> 优先级：P1 ｜ 批次 5（与方案 10 并行）｜ 依赖：方案 01~09 开发完成
> 前置阅读：`00-总体规划与执行约定.md`

## 1. 背景与现状

方案 01~09 的代码审查（2026-06-13，总负责人执行）整体结论是"质量高、可合并"，但发现若干工程债务，集中清理以免在后续迭代中放大。本方案不新增业务功能，只做清理和加固。

审查发现的问题：

1. **2 个空洞文档测试**：`tests/test_backtest_progress_docs.py` 和 `tests/test_development_progress_docs.py` 只断言 README/进度表里出现特定中文字符串，不测任何代码行为。改文案就会误报失败，提供零行为覆盖，是"为证明文档任务完成"而写的伪测试。
2. **新调度任务可复现性存疑**：触发评估、Agent 消费、复核、回测等新 `sync_task_type` 目前确认存在于本地 `runtime/base_data_scheduler/base_data_scheduler.json`，但该文件在 `.gitignore` 中。需确认 `data config export` 的预设（`personal-comprehensive`）能从零重新生成全部新任务，否则全新检出会缺任务。
3. **`market_bars_intraday` 孤儿表**：迁移 0015 建了分钟 K 线表但无写入方。方案 06 D1 已决策为"选项 A 保留预留"，需确认 `docs/数据库设计.md` 已标注，避免后人误以为有数据。
4. **GitNexus 差异记录待清理**：`docs/开发方案/GitNexus差异记录.md` 记录了开发期索引落后的处理。索引重建后，该文档应归档定稿（标注"索引已于 X 重建，以下为历史记录"），不再滚动追加。

## 2. 目标与非目标

**目标**

1. 把 2 个空洞测试改造为真实行为测试或删除，进度同步改用更轻量的机制。
2. 确认并保证全部调度任务可从预设重新导出，写一个防回归测试锁死。
3. 收口 `market_bars_intraday` 文档标注和 GitNexus 差异记录。

**非目标**

- 不改任何业务逻辑。
- 不动 `runtime/` 的本地内容（它本就不入提交）。

## 3. 技术方案

### 3.1 空洞文档测试改造

两个测试的本意是"防止开发完成后忘记同步文档"。这个意图合理，但实现方式错了——不该用全文字符串匹配。改造方案：

- **删除** `tests/test_backtest_progress_docs.py` 和 `tests/test_development_progress_docs.py` 中基于"特定中文句子是否出现"的断言。
- 如果仍想保留"文档存在性"的最低保障，改为：断言关键文档文件存在且非空、进度表中没有遗留"未开始"状态行（用结构化解析进度表的 markdown 表格，而非匹配具体句子）。这种断言对文案改写鲁棒。
- 文档与代码一致性的真正保障靠 review 和 `00` 的文档同步义务，不靠脆弱的字符串测试。

### 3.2 调度任务可复现性防回归

- 写测试 `tests/test_scheduler_jobs_regenerable_from_preset.py`：用 `personal-comprehensive` 预设构造 `DataSyncConfig`，调 `data config export` 的导出函数，断言生成的任务集合**包含**全部关键任务名：
  - `analytics.triggers.evaluate.daily` / `.intraday`
  - `agent.loop.consume`
  - `analytics.high_risk_reviews.*`
  - `analytics.reviews.due`
  - `analytics.backtest.weekly`
  - `analytics.technical_screening.ashare.main_board`
  - `analytics.universe.merge` / `analytics.universe.rebuild_avoid_pool`（若方案 05 已接）
- 若测试发现某任务只在本地 runtime json、预设里没有，补进 `sync_config.py` 的预设构造函数（这是真实缺陷修复，不只是加测试）。
- 这个测试同时是方案 10 的前置 PC4。

### 3.3 文档收口

- 确认 `docs/数据库设计.md` 中 `market_bars_intraday` 标注为"预留，当前无写入方，盘中能力由 realtime_quote_snapshots 承担"。缺则补。
- `docs/开发方案/GitNexus差异记录.md` 加一行收尾说明：索引已由总负责人重建，此前记录作为历史保留，后续如无新差异不再追加。
