# 持仓监控与无前视验证验收记录

## 已完成

- 盘中持仓监控独立运行器支持单次和循环模式、行情快照去重、失败退避、健康状态文件和信号退出。
- 监控动作通过触发事件唤醒 Agent；`exit` 映射为可执行卖出，T+1 不可卖出时保留原意图并降级为等待。
- 候选池刷新在同一事务追加不可变成员有效区间，历史查询按信号日过滤；缺少历史表或无法证明历史成员时研究 fail-closed。
- walk-forward 使用下一交易日开盘入场，纳入交易状态、热门板块、结构帧和数据完整性检查。
- 旧 `factor_score_topn` 回测只作为研究附件，不能作为策略上线门槛；新增历史、前向和运行时验证门控。
- 推荐任务依赖收盘市场状态、热门板块、结构计算和策略验证门控，门控不通过时允许观察/持仓管理，但禁止新增买入。

## 真实数据上线前提

- 候选池成员历史需持续积累至少 120 个独立截面。
- 策略需积累至少 60 个成熟 T+20 前向样本，并通过收益、置信区间、阶段、回撤、Rank IC、换手和可成交性门槛。
- 在真实数据不足期间，`allow_new_buys=false` 属于设计行为，不应通过手工配置绕过。
