## 发布方式

根 `docker-compose.yml` 保留开发挂载；发布时合并 `deploy/docker/compose.release.yml`，设置 `FINANCE_AGENT_HOST_RUNTIME_DIR` 为既有运行目录、`FINANCE_AGENT_HOST_ENV_FILE` 为既有环境文件。固定使用现有 Compose 项目名 `finance-agent`，不执行 `down -v`，不重建或清空数据库卷。

从提交的 Git 内容构建镜像，核查镜像内存在 `scripts/runtime/run_position_monitor.py`。发布后检查容器实际挂载、代码版本、API、策略准入输出、监控健康状态及浏览器页面；未完成上述检查不得标记为已部署验收。
