# 数据层采集优化进度表

本文档用于持久化记录“新闻、K 线全市场采集耗时过长且失败率较高”的改造进度。后续每完成一个阶段，都在此表更新状态，便于直接查看当前进展。

## 总体目标

将当前“全市场逐票高频扫 + 失败阻塞当前批次”的采集方式，改为“水位增量、重点优先、失败延迟重试、按数据源限流”的数据层链路。目标是让日常同步从数小时级降到分钟级，并让失败项可观测、可恢复、不阻塞整轮任务。
