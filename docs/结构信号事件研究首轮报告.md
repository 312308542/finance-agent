# structural-lite 事件研究首轮报告

## 研究协议

- 数据范围：A 股主板候选池中已写入 structural-lite 的 161 个资产、1,312 条指标帧。
- 事件：只读取 `payload.confirmed_at` 不晚于指标帧 `input_end_at` 的 SMC BOS/CHoCH、FVG、Elliott 和谐波事件。
- 收益：事件确认后 5、10、20 个交易日的方向收益、相对同批资产等权基准超额收益、胜率和最大不利收盘波动。
- 切分：按事件日期中位数 `2026-06-26` 划分样本内/样本外。
- 结果文件：`artifacts/structural_event_study_20260716.json`。
- 约束：本研究只读，不修改评分、推荐动作、风险门控或交易逻辑。

1. METHOD-001 保持执行中，下一轮需要覆盖至少两个更长历史周期，并补齐 20 日窗口后再复核。
