# 因子规格配置

本文记录当前数据层已经落地的因子计算规格。第一版目标不是建立完整量化研究平台，而是让 A 股和数字货币两条推荐链路都能稳定产出可解释、可追溯、可供 Agent 消费的结构化因子，并进一步支撑私人金融助手的持仓监控、观察池触发和换股比较。

## 1. 设计边界

- A 股和数字货币不混合推荐，因子可以共用服务形态，但窗口和字段口径分开配置。
- 指标和因子由确定性服务计算，LLM 不参与数值计算，只读取 `factor_frames`、`asset_scores`、`signal_snapshots`、`risk_findings` 和证据上下文做解释、比较和风险反驳。
- 上层 `PersonalFinanceAgent` 也不能直接计算因子，只能读取因子、评分、信号、风险、持仓和观察池上下文，决定是否触发底层金融团队 Workflow。
- 因子结果不仅服务推荐榜，也服务持仓监控、观察池启动条件、失效条件、换股比较和复盘。
- 缺少真实数据源的字段不强造，例如停复牌、ST、退市状态仍等待更稳定 Provider；当前只补已有表能支撑的历史分位和窗口派生。

## 3. 已补齐的派生因子

| 因子组 | 字段 | 数据来源 | 当前算法 |
| --- | --- | --- | --- |
| 估值 | `pe_percentile` | `fundamental_snapshots.pe_ttm` 历史 | 当前 PE 在历史窗口内的百分位 |
| 估值 | `pb_percentile` | `fundamental_snapshots.pb` 历史 | 当前 PB 在历史窗口内的百分位 |
| 估值 | `dividend_yield` / `dividend_score` | `fundamental_snapshots.payload` | 读取股息率并按 5% 满分线转换为得分 |
| 资金流 | `flow_rank_percentile` | `capital_flow_snapshots.payload` | 使用资金流排名和总数转换为 0-1 分位 |
| 资金流 | `flow_continuity` | `capital_flow_snapshots.main_net_inflow` | 最近 5 条资金流中净流入为正的占比 |
| 资金流 | `flow_price_divergence` | `capital_flow_snapshots.payload` | 优先读取 Provider 或归一化结果，不强行从行情猜测 |
| 流动性 | `amount_avg_20d` / `amount_zscore_20d` | `indicator_frames.payload.computed_values` | 复用 K 线成交额窗口和 z-score |
| 流动性 | `turnover_rate` / `illiquidity_score` | `capital_flow_snapshots.turnover_rate`、技术指标窗口 | 将成交额、换手率、波动和成交额异动压成非流动性分数 |
| 事件衰减 | `event_decay_score` | `event_records.published_at/collected_at` | 按 48 小时半衰近似做指数衰减 |
| 事件衰减 | `weighted_negative_event_count` / `weighted_positive_event_count` | `event_records.sentiment` | 新近负面事件扣分，新近正面事件小幅加分 |
| 衍生品 | `funding_rate_zscore` | `crypto_derivative_snapshots.funding_rate` 历史 | 当前资金费率相对窗口均值和标准差的 z-score |
| 衍生品 | `open_interest_change` | `crypto_derivative_snapshots.open_interest` 历史 | 当前 OI 相对 24 条窗口前的变化率，样本不足时回退到最早可用值 |
| 衍生品 | `open_interest_value_change` | `crypto_derivative_snapshots.open_interest_value` 历史 | 当前 OI 名义价值相对窗口前的变化率 |

## 4. 评分接入

`ScoringService` 已消费新增因子组：

| 市场 | 已接入组 |
| --- | --- |
| A 股 | `technical`、`fundamental`、`valuation`、`capital_flow`、`liquidity`、`event`、`event_decay`、`risk` |
| 数字货币 | `technical`、`derivatives`、`liquidity`、`event`、`event_decay`、`risk` |

### 4.1 策略权重配置

评分权重已从纯代码常量扩展为数据库策略中心：

| 能力 | 当前实现 |
| --- | --- |
| 策略表 | `scoring_strategies`，字段包含 `strategy_id`、`market`、`name`、`description`、`group_weights`、`missing_penalty`、`status` |
| 默认策略 | `strategy:ashare:balanced_growth`、`strategy:ashare:short_swing`、`strategy:ashare:defensive`、`strategy:crypto:crypto_swing` |
| CLI | `finance-agent data strategy init/list/show/set` |
| 回退规则 | 未传 `strategy_id` 时继续使用内置市场权重，保证旧推荐链路行为不变 |
| 可追溯字段 | `asset_scores.payload.strategy_id` 和 `asset_scores.payload.weight_snapshot` |

调度默认配置中，A 股推荐任务使用 `strategy:ashare:short_swing`，数字货币推荐任务使用 `strategy:crypto:crypto_swing`。单条推荐结果会把评分策略透传为：

- `asset_recommendations.payload.score_strategy_id`
- `asset_recommendations.payload.score_weight_snapshot`

推荐运行层会在 `recommendation_runs.payload.scoring_strategy_id` 记录本次使用的评分策略，方便从推荐榜或审计链复盘排序来源。

### 4.2 推荐入口质量闸门

推荐入口已完成以下质量闸门：

| 闸门 | 当前实现 |
| --- | --- |
| 多候选池合并 | `ProductionUniverseService.merge_universes` 支持同市场候选池按来源权重合并，调度任务类型为 `universe_merge` |
| 回避池剔除 | `UniverseRecommendationPipeline.run_for_universe` 接收 `avoid_universe_id`，在指标、因子、初筛和评分前剔除 `included=false` 回避成员 |
| 剔除审计 | `recommendation_runs.payload.avoid_pool_excluded` 记录剔除数量、标的、原因和回避池来源 |
| 研究池冷却 | `WatchlistService.get_research_intake_cooldown` 默认 7 天内阻止最近被 `removed/expired` 的标的自动重新入池 |
| 冷却审计 | 命中冷却时写入 `recommendation_skipped`，payload 中 `reason=cooldown`，并记录 `cooldown_until` 和最近退出事件 |

```powershell

```

验证时应重点检查 `factor_frames.payload.factor_groups` 中：

- A 股推荐链路：`valuation`、`capital_flow`、`liquidity`、`event_decay` 中的历史分位、连续性、流动性和事件衰减字段不再全部为空。
- 数字货币推荐链路：`derivatives`、`liquidity`、`event_decay` 中的 `funding_rate_zscore`、`open_interest_change`、`open_interest_value_change` 和事件衰减字段不再全部为空。

## 6. 后续 TODO

- A 股停复牌、ST、退市状态需要继续寻找稳定替代数据源，接入后进入风险因子和初筛硬过滤。
- A 股估值历史分位后续应扩展为更长周期，并区分行业内横截面分位和个股自身历史分位。
- 数字货币流动性因子还需要补交易深度、盘口价差、成交额稳定性和交易所异常状态。
- 事件衰减因子已完成基础版；后续需要细分新闻、公告、链上事件、龙虎榜、大宗交易和涨停池的不同权重。
- 观察池触发需要把 `watchlist_items.trigger_conditions` 映射到因子、信号和风险字段，例如资金流连续转正、技术信号转多、估值分位回落。
- 换股比较需要补当前持仓和候选标的的统一评分差、风险差、相关性和组合影响字段。
- 策略权重已完成基础配置中心；后续需要通过轻量回测补充各策略的绩效证据，再决定默认策略权重是否调整。
