# 因子规格配置

本文记录当前数据层已经落地的因子计算规格。第一版目标不是建立完整量化研究平台，而是让 A 股和数字货币两条推荐链路都能稳定产出可解释、可追溯、可供 Agent 消费的结构化因子。

## 1. 设计边界

- A 股和数字货币不混合推荐，因子可以共用服务形态，但窗口和字段口径分开配置。
- 指标和因子由确定性服务计算，LLM 不参与数值计算，只读取 `factor_frames`、`asset_scores`、`signal_snapshots`、`risk_findings` 和证据上下文做解释、比较和风险反驳。
- 缺少真实数据源的字段不强造，例如停复牌、ST、退市状态仍等待更稳定 Provider；当前只补已有表能支撑的历史分位和窗口派生。

## 2. 配置入口

代码入口：`src/finance_agent/factors/specs.py`

当前配置：

| 市场 | 配置 | 默认值 | 用途 |
| --- | --- | --- | --- |
| A 股 | `valuation_history_limit` | 120 | 估值历史分位最大读取窗口 |
| A 股 | `valuation_percentile_min_observations` | 3 | PE/PB 分位最小样本数 |
| A 股 | `dividend_full_score_yield` | 0.05 | 股息率达到 5% 时股息得分满分 |
| A 股 | `capital_flow_history_limit` | 20 | 资金流历史窗口最大读取条数 |
| A 股 | `capital_flow_continuity_window` | 5 | 主力资金连续性窗口 |
| A 股 | `main_flow_strength_scale` | 0.10 | 主力净流入/成交额达到 10% 时视为强流入 |
| 数字货币 | `derivative_history_limit` | 48 | 衍生品快照最大读取窗口 |
| 数字货币 | `funding_zscore_min_observations` | 6 | 资金费率 z-score 最小样本数 |
| 数字货币 | `open_interest_change_lag` | 24 | 未平仓量变化率对比窗口 |
| 数字货币 | `open_interest_positive_scale` | 0.15 | OI 变化率 15% 对应强正向拥挤信号 |

## 3. 已补齐的派生因子

| 因子组 | 字段 | 数据来源 | 当前算法 |
| --- | --- | --- | --- |
| 估值 | `pe_percentile` | `fundamental_snapshots.pe_ttm` 历史 | 当前 PE 在历史窗口内的百分位 |
| 估值 | `pb_percentile` | `fundamental_snapshots.pb` 历史 | 当前 PB 在历史窗口内的百分位 |
| 估值 | `dividend_yield` / `dividend_score` | `fundamental_snapshots.payload` | 读取股息率并按 5% 满分线转换为得分 |
| 资金流 | `flow_rank_percentile` | `capital_flow_snapshots.payload` | 使用资金流排名和总数转换为 0-1 分位 |
| 资金流 | `flow_continuity` | `capital_flow_snapshots.main_net_inflow` | 最近 5 条资金流中净流入为正的占比 |
| 资金流 | `flow_price_divergence` | `capital_flow_snapshots.payload` | 优先读取 Provider 或归一化结果，不强行从行情猜测 |
| 衍生品 | `funding_rate_zscore` | `crypto_derivative_snapshots.funding_rate` 历史 | 当前资金费率相对窗口均值和标准差的 z-score |
| 衍生品 | `open_interest_change` | `crypto_derivative_snapshots.open_interest` 历史 | 当前 OI 相对 24 条窗口前的变化率，样本不足时回退到最早可用值 |
| 衍生品 | `open_interest_value_change` | `crypto_derivative_snapshots.open_interest_value` 历史 | 当前 OI 名义价值相对窗口前的变化率 |

## 4. 验证入口

候选池级冒烟脚本已补充样例历史快照，会同时验证新因子：

```powershell
.\.venv\Scripts\python.exe scripts\data\run_universe_recommendation_smoke.py --market ashare
.\.venv\Scripts\python.exe scripts\data\run_universe_recommendation_smoke.py --market crypto_spot
```

验证时应重点检查 `factor_frames.payload.factor_groups` 中：

- A 股推荐链路：`valuation`、`capital_flow` 中的历史分位和连续性字段不再全部为空。
- 数字货币推荐链路：`derivatives` 中的 `funding_rate_zscore`、`open_interest_change` 和 `open_interest_value_change` 不再全部为空。

## 5. 后续 TODO

- A 股停复牌、ST、退市状态需要继续寻找稳定替代数据源，接入后进入风险因子和初筛硬过滤。
- A 股估值历史分位后续应扩展为更长周期，并区分行业内横截面分位和个股自身历史分位。
- 数字货币流动性因子还需要补交易深度、盘口价差、成交额稳定性和交易所异常状态。
- 事件衰减因子需要等新闻、公告、链上事件统一进入事件表后再计算。
